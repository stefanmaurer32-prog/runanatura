# RUNA NATURA – Designprototyp V3
Next.js App Router. Lokal: npm install, npm run dev. Render Web Service: Build `npm install && npm run build`, Start `npm start`. Node 22.
Eigenständiger Prototyp, nicht mit bestehendem Repository zusammengeführt. Vor Upload separaten Branch oder neues Repository nutzen. Keine vorhandenen Admin-/Supabase-Dateien überschreiben.
Bildmaterial: Ausschnitte aus den gelieferten Entwürfen, keine Originalfotos oder Original-Logodatei. Romla fehlt; Georgia als Ersatz. Comfortaa über Google Fonts (vor Veröffentlichung lokal hosten). Illustrationen und Logo durch freigegebene Einzeldateien ersetzen. Newsletter ist eine ausdrücklich nicht speichernde Demo; kein Versand, keine Buchung, keine Zahlungen, kein Admin. Kontakt- und Workshopdaten sind offen. Rechtliche Angaben ergänzen. Keine Live-Freigabe vor Integration und Tests.
